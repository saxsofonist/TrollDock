# История изменений

## 1.1.1

- Убрана ошибочная блокировка подписи из-за различия App ID профиля и Bundle ID приложения.
- Сохраняются исходные Bundle ID основного приложения и расширений.
- Сохранены проверки сертификата, закрытого ключа, целостности и срока действия профиля, а также разрешённого устройства.
- Подписыватель обновлён до zsign 1.1.3-trolldock.2.

## 1.1.0

- Добавлена вкладка установки IPA с сертификатом P12/PFX и профилем `.mobileprovision`.
- Добавлено сохранение именованных сертификатов, профилей и паролей с Windows DPAPI.
- Подписанные копии и временные данные автоматически удаляются без корзины; исходная IPA остаётся без изменений.
- Добавлены настройки стартовой вкладки и порядка вкладок.
