# TrollDock 1.3.1 — исправление настройки пароля root

Исправлен случай, когда кнопка **«Задать пароль root»** останавливалась с сообщением «Системная утилита требует текущий пароль root». Вместо интерактивного `passwd` используется административная утилита bootstrap `pw` через `sudo`. Предыдущий пароль root для этой операции не нужен.

1. Подключите и выберите iPhone.
2. Нажмите «Задать пароль root».
3. Введите пароль mobile и новый пароль root дважды.
4. Программа откроет SSH-туннель, выполнит смену пароля и проверит новый пароль отдельным входом root.

Сохранение нового пароля на ПК — по желанию, с шифрованием Windows DPAPI. Пароль mobile не сохраняется. Пароли не передаются в командной строке и не попадают в журнал. Если смена могла завершиться, но вход root не подтверждён, программа показывает это отдельно.

Функция требует работающий OpenSSH, разрешение sudo для mobile и утилиту `pw` из bootstrap. Такой интерфейс управления паролем используется в [Dopamine](https://github.com/opa334/Dopamine/blob/2.x/Application/Dopamine/Jailbreak/DOEnvironmentManager.m). Если нужной утилиты нет, программа сообщит об этом до передачи нового пароля. Пакетная установка IPA/DEB, сохранённые сертификаты и порядок вкладок сохранены.

**Скачать:** `TrollDock-1.3.1-win-x64.zip`. Распакуйте целиком. При обновлении сохраните папку `data`.

Пройдены 27 проверок протокола и обработки ошибок, 41 проверка WPF-интерфейса и 5 сценариев с настоящим SSH к локальному тестовому серверу. Они охватывают передачу пароля только через stdin, вход через sudo, отсутствие утилиты, разбиение ответа SSH на части, ошибки и отдельную проверку входа root. Сборка без предупреждений.

Смена пароля на реальном iPhone в рамках этого релиза не выполнялась. Исходный код — в репозитории и source ZIP; контрольные суммы — в `SHA256SUMS.txt`.
