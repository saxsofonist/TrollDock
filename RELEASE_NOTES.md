# TrollDock 1.2.0 — пакетная установка

Добавляйте сразу несколько файлов через диалог выбора или перетаскивание. Пакетная установка работает во всех режимах: **IPA · TrollStore**, **IPA · Сертификат** и **DEB · Dopamine**.

- Очередь показывает имя и результат каждого файла. Есть удаление выбранных строк и очистка; дубликаты не добавляются.
- IPA устанавливаются по очереди. Для всей очереди используется одно SSH-подключение или один выбранный сертификат.
- DEB устанавливаются общей операцией APT, чтобы выбранные локальные пакеты могли удовлетворять зависимости друг друга. Результат проверяется для каждого пакета.
- Остановка очереди не прерывает уже начавшуюся установку. При повторном запуске подтверждённые установки пропускаются.
- Исходные IPA/DEB остаются нетронутыми. Подписанные временные копии удаляются без корзины после каждого приложения.

**Скачать:** `TrollDock-1.2.0-win-x64.zip`. Распакуйте целиком и запустите `TrollDock.exe`; .NET и подписыватель уже включены. При обновлении сохраните папку `data` со своими настройками и зашифрованными сертификатами.

Проверено: 17 проверок очереди, 24 проверки WPF-интерфейса, 94 проверки установки и очистки, 39 проверок DEB. Сборка без предупреждений. Пакетная установка на реальном iPhone пока не проверялась; локальные тесты не устанавливают приложения или пакеты на телефон.

Исходники находятся в репозитории и source ZIP, контрольные суммы — в `SHA256SUMS.txt`.
