# TrollDock 1.3.0 — пароль root из программы

В разделе **«Доступ SSH и дополнительные настройки»** появилась кнопка **«Задать пароль root»**. Она помогает настроить root на iPhone, если пароль ещё не задан, через доступную учётную запись mobile с правами sudo.

1. Подключите и выберите iPhone.
2. Нажмите «Задать пароль root».
3. Введите пароль mobile и новый пароль root дважды.
4. Программа откроет SSH-туннель, выполнит смену пароля и проверит новый пароль отдельным входом root.

Сохранение нового пароля на ПК — по желанию, с шифрованием Windows DPAPI. Пароль mobile не сохраняется. Пароли не передаются в командной строке и не попадают в журнал. Если смена могла завершиться, но вход root не подтверждён, программа показывает это отдельно.

Функция требует работающий OpenSSH и разрешение sudo для mobile. Пакетная установка IPA/DEB, сохранённые сертификаты и порядок вкладок сохранены.

**Скачать:** `TrollDock-1.3.0-win-x64.zip`. Распакуйте целиком. При обновлении сохраните папку `data`.

Проверено: 23 проверки протокола смены пароля и обработки ошибок, 41 проверка WPF-интерфейса и 3 сценария с настоящим SSH-подключением к локальному тестовому серверу. Сборка без предупреждений.

Смена пароля на реальном iPhone в рамках этого релиза не выполнялась. Исходный код — в репозитории и source ZIP; контрольные суммы — в `SHA256SUMS.txt`.
