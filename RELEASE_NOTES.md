# TrollDock 1.1.1 — исправление установки с сертификатом

Убрана ошибочная блокировка подписи при различии между App ID профиля `.mobileprovision` и Bundle ID приложения. В версии 1.1.0 эта проверка могла останавливать работу с профилем, который использовался в других подписывателях.

TrollDock сохраняет исходные Bundle ID основного приложения и всех расширений. Проверки сертификата, ключа, целостности и срока действия профиля, а также разрешённого устройства сохранены. Подписыватель обновлён до **zsign 1.1.3-trolldock.2**.

Исходная IPA остаётся без изменений. Подписанная копия и временные данные удаляются без корзины после установки, ошибки или отмены.

Скачайте `TrollDock-1.1.1-win-x64.zip`, распакуйте целиком и запустите `TrollDock.exe`. Обновите и папку `tools`; .NET уже включён. Для сохранения настроек и сертификатов оставьте свою папку `data`.

Проверено: 41 проверка сертификатов, 93 проверки процесса установки и очистки, 233 проверки инструментов и криптографических подписей. Дополнительно реальная IPA успешно подписана действующим Apple-сертификатом; криптографическая подпись, сохранение Bundle ID и исходного файла, удаление временных файлов проверены. Установка и запуск этой сборки на iPhone пока не проверялись.

Контрольные суммы файлов находятся в `SHA256SUMS.txt`. Исходный код доступен в репозитории и отдельном source ZIP.
